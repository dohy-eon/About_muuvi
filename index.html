muuvi – 감정 기반 콘텐츠 추천 플랫폼

💡 한 줄 소개

OpenAI 임베딩과 Supabase 벡터 검색을 활용해, 사용자의 감정과 장르 조합에 따라 콘텐츠를 추천하는 감정형 AI 큐레이션 플랫폼.

기획 배경

📌 문제 인식

  • OTT 플랫폼이 너무 많아, "뭘 볼지 고르기"가 피로감의 원인이 됨.
  • 기존 추천 시스템은 장르 중심이라 사용자의 '감정적 맥락'을 반영하지 못함.

💭 인사이트

  • 실제 시청자는 "오늘 기분에 맞는 콘텐츠"를 찾고 싶어 함.
  • 따라서, 무드(Mood) + 장르(Genre) 조합을 통해 감정 기반 추천 경험을 제공.

핵심 기능 (기획 및 개발)

🎨 온보딩 플로우 (Recoil 기반)

사용자가 ‘장르(영화/애니/드라마)’와 ‘무드(힐링/몰입/짜릿 등)’를 단계별로 선택하면, Recoil atom을 통해 전역 상태로 저장

🧠 AI 시맨틱 추천 (OpenAI + Supabase 벡터 검색)

사용자의 무드/장르 조합을 OpenAI 임베딩으로 변환 후, Supabase(pgvector)에서 유사도 기반 검색 수행

🎥 TMDB 연동 데이터 파이프라인

Supabase Edge Function(populate-db)이 TMDB API에서 콘텐츠를 수집 및 저장

🧩 AI 임베딩 자동화 파이프라인

TMDB로 가져온 콘텐츠 설명을 OpenAI text-embedding-3-small 모델로 벡터화 후 Supabase에 저장 (embed Function)

🔍 실시간 벡터 검색 기반 추천

사용자가 입력한 감정/장르 조합을 벡터로 변환해 Supabase RPC(match_contents)로 유사 콘텐츠 검색

🎬 콘텐츠 카드 UI 렌더링

TMDB 이미지, 제목, 평점, 설명을 카드 컴포넌트로 표시

💾 즐겨찾기 기능 (확장 예정)

사용자 계정 기반의 콘텐츠 저장 및 다시보기 구조 설계 완료

시스템 아키텍처

전체 데이터 흐름:

  • TMDB → Supabase (Edge Function: populate-db)

    TMDB API에서 콘텐츠 데이터 수집 → DB 저장

  • Supabase → OpenAI Embedding (Edge Function: embed)

    콘텐츠 설명을 벡터화(1536차원) 후 contents.vector 컬럼에 저장

  • User → Onboarding Flow (Frontend)

    사용자 장르 + 무드 선택 → Recoil 전역 상태 저장

  • Frontend → Supabase (AI 검색)

    선택한 무드/장르를 벡터화 → Supabase RPC(match_contents) 호출

  • DB → Frontend (결과)

    코사인 유사도 기반 상위 콘텐츠 리스트 반환 → UI로 렌더링

결과 및 성과

  • TMDB 데이터 자동 임베딩 파이프라인 구축
